# Echo (প্রতিধ্বনি)

**Where it goes in the book:** Book pages 201–202, topic 7.3.1 প্রতিধ্বনি: after the paragraph that works out the 16.5 m distance for an echo, before the bat paragraph.

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="echo/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './echo/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
