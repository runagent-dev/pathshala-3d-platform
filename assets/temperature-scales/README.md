# Temperature scales (তাপমাত্রার স্কেল)

**Where it goes in the book:** Book page 163, topic 6.2.

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="temperature-scales/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './temperature-scales/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
