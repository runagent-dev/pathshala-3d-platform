# Parked (dev only, never packaged)

The first version of `reflection-laws` taught four steps. The owner split them into separate figures (brief,
"OWNER'S SECOND DIRECTION"), so this figure keeps only 8.2.1 and calm or wavy water. What was taken out is kept here for
the builders of the next figures. It is a snapshot of a working version, with thick rays (the owner asked for thin ones).

- **8.2 তিন ঘটনা (চিত্র ৮.০২):** `four-step-version/app.js` (`shine`, the `events` branch of `applyWorld`, the `events` test
  question), `diagram.js` (`drawRefracted`, `drawAbsorbed`), the `rule_ev*` strings in `i18n.js`.
- **চিত্র ৮.০৫ (Fresnel):** `app.js` (the `amount` branch; `elNow`, which lowers the view with θi so the water really turns
  into a mirror), `panelparts.js` (`fresnelGraph`, water and glass), the `rule_a*` strings. `four-step-version/reading.js` keeps
  `fresnel`, `percent`, `snell` and `refracted`, and `src/lake.js` keeps the exact Fresnel water.
- **The magnifier on wavy water:** `panelparts.js` (`createMagnifier`), a live section through the same waves.
