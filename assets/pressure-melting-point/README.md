# Pressure and melting point: a wire cuts through ice (গলনাঙ্কের ওপর চাপের প্রভাব)

**Where it goes in the book:** Book page 181, topic 6.7.

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="pressure-melting-point/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './pressure-melting-point/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
