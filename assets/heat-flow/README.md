# Internal Energy and Flow of Heat (অভ্যন্তরীণ শক্তি ও তাপের প্রবাহ)

**Where it goes in the book:** Book page 162, topic 6.1.1.

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="heat-flow/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './heat-flow/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
