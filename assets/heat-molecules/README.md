# Heat and temperature: molecules of a solid, a liquid and a gas (তাপ ও তাপমাত্রা)

**Where it goes in the book:** Book page 161, topic 6.1.

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="heat-molecules/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './heat-molecules/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
