# Stopwatch (থামা ঘড়ি)

**Where it goes in the book:** Book page 23, topic 1.6.3: থামা ঘড়ি (Stop Watch). Next to Figure 1.10 (চিত্র ১.১০, stopwatch), or in place of that photo.

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="stopwatch/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './stopwatch/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
