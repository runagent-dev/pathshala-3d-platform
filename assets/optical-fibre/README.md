# Optical fibre (অপটিক্যাল ফাইবার)

**Where it goes in the book:** Book page 253, topic 9.3.1 অপটিক্যাল ফাইবার, চিত্র ৯.১১ (a) and (b), and the 1.50 / 1.45 example (সংকট কোণ 75°).

Interactive 3D figure for the Pathshala book.

## Embed

```html
<iframe src="optical-fibre/index.html" style="width:100%;aspect-ratio:16/10;border:0" allow="fullscreen" loading="lazy"></iframe>
```

To listen to it or control it from the book page, use the helper shipped in the zip:

```html
<script type="module">
  import { connectAsset } from './optical-fibre/shared/lib/host.js';
  const figure = connectAsset(document.querySelector('iframe'));
  await figure.ready;
  figure.on('change', (state) => console.log(state));
</script>
```
